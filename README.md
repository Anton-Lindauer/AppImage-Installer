# AppImage-Installer

A console-based tool to easily install AppImage files on Linux.

You can move the AppImage file to the right directory, make the file executable and soon you can also create a desktop startmenu entry.

You need Python version 3.13 or higher to use this program.
No external libraries required.

This tool is still work in progress and more functionality will be added soon. For now, the directory the files are moved to are for testing purposes only.
